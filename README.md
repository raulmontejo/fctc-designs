# fctc-designs

Design assets for **Forest City Tech Coop** — a worker-owned tech cooperative in Cleveland Heights, OH.

The canonical design lives in this repo as static HTML + reference screenshots — no Figma account or subscription needed to work on it.

- **Brand kit** — [`brand_kit/fctc-style-tile.html`](brand_kit/fctc-style-tile.html)
- **Homepage mock (HTML)** — [`hifi_mocks/fctc-home.html`](hifi_mocks/fctc-home.html) — the source of truth for the design
- **Reference screenshots** — [`hifi_mocks/screenshots/`](hifi_mocks/screenshots/)
- **Figma design system + homepage** (frozen handoff artifact, derived from the HTML) — [figma.com/design/6EVaUnDG6k1jOoDZVV7Vd4](https://www.figma.com/design/6EVaUnDG6k1jOoDZVV7Vd4)

See [`CLAUDE.md`](CLAUDE.md) for a fuller map of this repo and implementation notes.
